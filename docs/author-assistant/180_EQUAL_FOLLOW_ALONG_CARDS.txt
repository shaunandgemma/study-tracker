180. EQUAL FOLLOW ALONG CATALOGUE CARDS

1. Request
Make every Follow Along catalogue card the same size and stop long descriptions from expanding individual cards.

2. Cause of the empty glowing box
The card always rendered the old progress-summary loading placeholder, even when a published Follow Along supplied no progress information.

3. Changes
- Set every catalogue card to one consistent height.
- Limit titles to two visible lines.
- Limit descriptions to three visible lines.
- Keep the action button aligned at the bottom.
- Show the progress-summary area only when genuine progress information exists.

4. Preserved behaviour
- Full Follow Along descriptions remain unchanged in the programme itself.
- Available and Coming Soon actions remain unchanged.
- A genuine progress summary can still be displayed when one is supplied.
- No Author, Supabase, AWS, approval, candidate or publishing behaviour was changed.

5. Verification
- Added a regression check for equal-height classes and shortened catalogue text.
- Added a regression check that cards without progress do not render the empty animated placeholder.
