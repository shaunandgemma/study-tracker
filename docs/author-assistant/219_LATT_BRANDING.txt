===================

1. PURPOSE
----------
Replace the user-visible ExamPulse name with LATT.

LATT stands for:

Learning All Things Tech

2. UPDATED
----------
1. Main navigation name and home accessibility label.
2. Application landing-page description.
3. Safe demo welcome screen and demo email.
4. Application footer.

3. DATA-SAFETY BOUNDARY
-----------------------
The old exampulse_* browser-storage keys remain unchanged internally.

They are not user-visible branding. Keeping them prevents existing exams, checklist progress, flags, history, theme settings and archived progress from appearing to disappear after the rename.

Historical database migration comments and old verification reports also remain unchanged because they record the name used when those historical actions occurred.

4. RESULT
---------
The active application now displays LATT and Learning All Things Tech. Existing locally stored learner data remains compatible.
