STEP 172 - SELECTABLE AND COPYABLE INSTRUCTIONS

1. Instruction wording can now be highlighted normally with the mouse.

2. Highlighting text does not tick or untick the learner checkbox.

3. Each instruction has a Copy action that copies its main text and optional detail.

4. The checkbox remains a separate control for learner progress.

5. This is a display-only improvement. It does not change drafts, candidates,
approvals, publishing, Supabase data or AWS resources.
