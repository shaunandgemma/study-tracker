197. TERRAFORM CONFIGURATION FOUNDATIONS FOLLOW ALONG 0

1. PURPOSE
Create the first Terraform learning experience as Follow Along 0 so learners
understand how Terraform configuration is formed before using complete files in
the existing Follow Alongs.

2. PROGRAMME
Title: Understanding and Building Terraform Configuration
Programme ID: terraform-configuration-foundations-learning-path
Exam ID: terraform-associate-004
Level: Beginner

3. TEACHING METHOD
The learner reads HCL anatomy first, creates every file from empty, adds one
block or concept at a time, explains arguments and references, and runs format
and validation checks throughout. Finished file blocks are comparison aids and
are shown only after the learner has constructed the relevant content.

4. CONTENT
6 phases, 9 tasks, 146 separately editable checkboxes, 57 CLI commands,
19 verification checks and 6 ordered cleanup items.

The learner builds versions.tf, providers.tf, variables.tf, terraform.tfvars,
locals.tf, data.tf, main.tf and outputs.tf. The lab teaches blocks, labels,
arguments, literal and reference expressions, types, defaults, validation,
locals, a data source, for_each, each.key, each.value, resource addresses,
outputs, prediction, plan review, controlled change and safe teardown.

5. SOURCES
Only official AWS and HashiCorp documentation is linked. The package contains
4 AWS sources and 15 HashiCorp Terraform sources.

6. CARD ORDER
The Terraform Follow Along page assigns this programme Follow Along 0 and sorts
it before the existing beginner and state/backend programmes. The existing
programmes remain unchanged.

The builder and tests do not connect to AWS, Supabase or Author. They do not
