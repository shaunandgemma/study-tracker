4. CONFIRMED CAUSE

Migration 20260819 created a protected table named:
follow_along_publishable_programmes

The protected publishing function permits a service only when its exact programme ID and service slug have an enabled row in this table.

The existing migration enabled only:

Programme ID: lambda-learning-path
Service slug: lambda
Publish token: LAMBDA

The approved SQS package uses:

Programme ID: sqs-learning-path
Service slug: sqs
Publish token required by the UI: SQS
Service name: Amazon Simple Queue Service

No enabled SQS allow-list row exists, so the database correctly refused the request.

5. REQUIRED SEPARATE FIX

Service name: Amazon Simple Queue Service
Enabled: true
