4. WHAT IT SAVES

It saves one session file and one research-request file.

On Windows, the normal session location is:

%LOCALAPPDATA%\StudyTracker\AuthorAssistant

The script displays the exact research-request location after saving.

5. RESUME BEHAVIOUR

When a saved session exists, the script offers to resume it.

Choosing Yes reuses the same session.
It does not create a duplicate.

Choosing No starts a new session.
