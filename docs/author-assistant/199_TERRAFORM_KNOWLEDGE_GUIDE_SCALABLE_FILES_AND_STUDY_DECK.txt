199. TERRAFORM KNOWLEDGE GUIDE SCALABLE FILES AND STUDY DECK

1. PURPOSE
Make every Terraform Knowledge Guide lesson independently editable and add an ordered Study Deck without changing the established lesson design.

2. WHAT WOULD YOU LIKE TO DO PAGE
Terraform now displays four choices in this order:
1. Knowledge Guide.
2. Checklist.
3. Prep Exam.
4. Follow Alongs.

Opening Knowledge Guide starts at lesson 1 of 37.

3. STUDY DECK NAVIGATION
The learner can use Previous lesson and Next lesson.
The lesson number is displayed.
The sequence is exactly the same as the Terraform checklist sequence.
The established lesson sections and visual layout are preserved.

4. QUICK-SCOPE BUTTONS
Every checklist row keeps its Study button.
The button opens that exact lesson immediately.
The checklist remains available as a quick overview and progress tracker.

5. INDIVIDUAL LESSON FILES
Each clickable row now has its own file under:
src/data/terraformKnowledgeGuide/

The files are grouped into:
objective-1
objective-2
objective-3
objective-4
objective-5
objective-6
objective-7
objective-8

Example:
src/data/terraformKnowledgeGuide/objective-1/tf004-1a.js

6. CONNECTION FILE
src/data/terraformKnowledgeGuide/index.js imports all 37 lesson files and preserves their checklist order.

src/data/terraformKnowledgeGuide.js remains as a small compatibility entry point so existing app imports continue to work.

7. UNCHANGED BOUNDARIES
Checklist progress storage is unchanged.
The Terraform lesson page design is unchanged.
AWS and other exams are unchanged.
Follow Alongs, Author, Approvals, Supabase and publishing are unchanged.
