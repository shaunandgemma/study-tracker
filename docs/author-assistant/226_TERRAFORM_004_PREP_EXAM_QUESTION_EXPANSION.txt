226. TERRAFORM ASSOCIATE 004 PREP EXAM QUESTION EXPANSION

1. PURPOSE

Review the Terraform Associate 004 Prep Exam question bank, improve its exam quality, and add 20 new questions without making correct answers obvious from their length.

2. OFFICIAL STANDARD CHECKED

The question bank was checked against HashiCorp's current Terraform Associate 004 content list, learning path, and sample-question format.

The current exam learning path states that the exam tests Terraform 1.12.

Official references:
- https://developer.hashicorp.com/terraform/tutorials/certification-004/associate-review-004
- https://developer.hashicorp.com/terraform/tutorials/certification-004/associate-study-004
- https://developer.hashicorp.com/terraform/tutorials/certification-004/associate-questions-004

3. CHANGES MADE

- Reworked the original 30 questions to use clearer exam-style wording and more realistic situations.
- Replaced weak or obviously incorrect distractors with plausible alternatives.
- Balanced option wording so the correct answer is not revealed by being much longer than the others.
- Added 20 new questions, producing 50 questions in total.
- Covered all eight official Terraform Associate 004 objective groups.
- Included single-answer and select-two question formats.
- Added explanations that teach why the correct choice is right and clarify important limitations.
- Kept the app's existing runtime question and answer shuffling.

4. NEWLY STRENGTHENED COVERAGE

- Provider requirements, aliases, child-module provider passing, and provider upgrades.
- Saved plans, stale plans, formatting, validation, and the core workflow.
- Resource and data blocks, variable precedence, complex types, for expressions, dependencies, lifecycle, and custom conditions.
- Sensitive, ephemeral, and provider-supported write-only values.
- Module inputs, outputs, sources, scope, and Registry version constraints.
- Local and remote state, locking, backend initialization, drift, moved blocks, removed blocks, and refresh-only mode.
- Import blocks, CLI import concepts, state inspection, and diagnostic logging.
- HCP Terraform workspaces, VCS runs, projects, variable sets, permissions, policies, run triggers, and dynamic credentials.

5. QUALITY SAFEGUARDS

Automated checks now verify:
- Exactly 50 unique questions exist.
- Every question belongs to a valid official objective group.
- Every correct-answer index is valid.
- Select-two questions contain exactly two correct answers.
- Options are not duplicated within a question.
- Explanations contain enough detail to teach the topic.
- A correct option is not a conspicuous length outlier compared with its distractors.
- All eight objective groups are represented.
