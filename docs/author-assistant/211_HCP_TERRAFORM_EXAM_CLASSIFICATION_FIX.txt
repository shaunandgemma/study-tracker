211. HCP TERRAFORM EXAM CLASSIFICATION FIX

1. Problem
The published HCP Terraform Remote Runs and Collaboration Follow Along did not appear in the Terraform workspace.

2. Cause
The offline manuscript stored the readable workspace name, but the generated programme did not store the app exam ID. The published-card fallback therefore assigned it to AWS SAA-C03.

3. Local app correction
The offline importer now converts a Terraform workspace name to terraform-associate-004 for future packages.

4. Existing published programme compatibility
The published catalogue recognises the Terraform category and the hcp-terraform programme prefix. The already-published programme therefore appears in the Terraform workspace without another import, candidate, approval or publication.

5. Preserved boundaries
No Author draft, Shared Draft, candidate, approval, published database row, Supabase resource or AWS resource was changed.
