214. OFFLINE SCHEMA AND PAIR PROTECTION

1. Alternate offline schema support
The local converter now translates browserSteps, cliBlocks, editableBlocks and verificationChecks into the controlled Author handoff structure without another AI request.

2. Cleanup translation
Grouped offline cleanup records are expanded locally so every recorded resource keeps an exact cleanup target, source-linked instructions and verification.

Official HashiCorp Vault documentation is accepted for Terraform Follow Alongs that genuinely use the Terraform Vault provider. Other unrelated HashiCorp product paths remain outside this Author source boundary.

3. Preview and JSON protection
Before any handoff folder is created, the importer now checks that the Markdown heading matches the JSON programme title, the training prefix is present and every JSON task ID appears in the preview.

4. Safe failure
A mismatched pair stops before conversion and cannot be mistaken for an existing Follow Along session.

5. Boundaries
The converter does not call AI, Author, Supabase, AWS, HCP Terraform, candidate, approval or publishing services.
