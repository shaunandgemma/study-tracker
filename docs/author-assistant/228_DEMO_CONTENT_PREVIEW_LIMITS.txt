228. DEMO CONTENT PREVIEW LIMITS

1. PURPOSE

Demo Mode now gives visitors a useful preview without displaying the complete learning library.

2. FIXED DEMO ALLOWANCE

- Exam questions: the same first 10 questions for each exam.
- Follow Alongs: the first 2 available programmes for each exam.
- Troubleshooting Challenges: the first 2 ordered challenges for each exam.
- Checklists: the first 10 checklist rows for each exam.
- Knowledge Guides: the 10 pages matching those first 10 checklist rows.

3. QUESTION BEHAVIOUR

The source questions remain the same between Demo visits. The app may still shuffle their display order and answer choices so the preview behaves like a real practice session.

The AWS Demo preview does not run the normal 65-question Full Mock validator. Normal learner and administrator accounts keep the existing 65-question AWS behaviour unchanged.

Balanced custom selection is unavailable in Demo Mode because a 10-question sample may not contain enough questions from every official domain. Demo custom sessions use the fixed sample with random selection instead.

4. DIRECT OPENING BOUNDARY

Demo users can open Follow Alongs and Troubleshooting Challenges only from their reduced visible lists. A legacy direct Follow Along request is cleared when Demo Mode is active.

5. DATA SAFETY

Demo exam, checklist, Follow Along and Troubleshooting progress remains temporary and memory-only. Demo Mode still performs no Author, Approver, Supabase write or AWS action.

6. IMPORTANT SECURITY NOTE

These limits control what the application displays and allows a Demo visitor to open. Because the application is a browser-delivered frontend, this is a product preview boundary rather than encryption or digital-rights protection for bundled static files.
