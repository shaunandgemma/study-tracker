213. REMOVE RESOURCE RETENTION POPUP

1. Removed behaviour
The Resource Retention Decision popup no longer appears when the learner selects Next Task.

2. New task transition
Next Task saves any unsaved checkbox or resource-binding progress, marks the current task complete, retains saved bindings for connected instructions and advances immediately.

3. Cleanup boundary
Study Tracker still does not delete AWS, HCP Terraform or other provider resources. Manual cleanup instructions and the final cleanup area remain available.

4. Coverage
The popup was removed from both the shared published Follow Along runner and the retired VPC runner so it cannot return through either interface.

5. External systems
No Author, Supabase, AWS, HCP Terraform, candidate, approval or publishing operation was performed.
