198. TERRAFORM KNOWLEDGE GUIDE

1. PURPOSE
The Terraform Knowledge Guide is now the first learning option in the local Terraform exam workspace.

2. LEARNER FLOW
Open the Terraform Associate exam.
Open Knowledge Guide.
Choose Study beside any checklist row.
Read the detailed lesson.
Return to the guide and tick the row only when the subject is understood.

3. LESSON STRUCTURE
Each of the 37 Terraform checklist objectives has its own page containing:
- A plain-English explanation.
- Why the subject matters.
- A workplace example.
- What to understand for the exam.
- A common beginner mistake.
- Key points to remember.
- A small code example where it helps.
- Official HashiCorp learning links.

4. SAFETY AND SCOPE
This change is limited to the Terraform Knowledge Guide.
Existing checklist progress storage is unchanged.
AWS and other exam checklists are unchanged.
Follow Alongs, Author, Approvals, Supabase and publishing are unchanged.
No PDF system was added.
