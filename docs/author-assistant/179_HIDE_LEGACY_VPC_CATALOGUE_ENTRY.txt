STEP 179 - HIDE THE LEGACY VPC CATALOGUE ENTRY

1. Approved scope

Hide only the retained legacy VPC Learning Path card from the normal learner
Follow Alongs catalogue.

2. Preserved items

The VPC programme definition, 45 tasks, eight phases, components, services,
validation registry, direct compatibility route, browser progress and Supabase
progress/resource rows remain unchanged. No VPC file or database data is deleted.

3. Learner catalogue behaviour

The normal Follow Alongs landing page now starts from an explicitly visible
catalogue that excludes vpc-learning-path. The same visibility check is applied
after database-published cards are merged, so the legacy ID cannot be restored
to the landing page accidentally by a matching published row.

4. Reversibility

The change is reversible by removing vpc-learning-path from the hidden ID list.
It does not require a database migration.

5. Safety

Controlled published Follow Alongs remain database-backed and visible. Author,
Approver, candidate, publishing, exam and learner-progress behaviour is not
changed.
